# Tutorial 02: E2E Testing

This tutorial will cover end-to-end testing strategies for React Native apps using:

- **Detox**: Gray-box E2E testing framework for mobile apps
- **Maestro**: Simple, declarative mobile UI testing

## Prerequisites

- Complete the initial setup in the root README
- Working mobile app that can run on simulator/emulator
- For Detox: Xcode (iOS) or Android Studio (Android)
- For Maestro: Maestro CLI installed
