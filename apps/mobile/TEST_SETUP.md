# Mobile App Testing

Component testing for the mobile app will be covered in the **E2E Testing** tutorial (Tutorial 02).

The mobile app uses:

- **Jest** as the test runner
- **@testing-library/react-native** for component testing
- **@react-native/jest-preset** for React Native environment

The full testing setup, including component tests and integration tests, will be implemented as part of the tutorial series.

For now, the mobile app structure and API client are in place and ready for testing.
